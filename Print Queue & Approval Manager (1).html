How Phone Connects to PC (Ethernet / Internet Setup)

No PC Wi-Fi card needed! Connect via Ethernet router or Free Internet Hosting

Ethernet Friendly
Option 1: Free Netlify / GitHub Hosting (Easiest)

Upload this single index.html file to free Netlify, Vercel, or GitHub Pages. Paste your website link below. Mobile phones on 4G/5G/Wi-Fi can scan and print from anywhere!

Option 2: Internet Tunnel (ngrok)

Run ngrok http 8000 on PC. Copy the generated internet URL (e.g., https://xyz.ngrok-free.app) into the field below. Works directly over PC Ethernet cable!

Option 3: Ethernet Cable connected to Wi-Fi Router

If your Ethernet cable plugs into a Wi-Fi router, PC does NOT need a Wi-Fi card! Phones on that router's Wi-Fi can open your PC IP (e.g. http://192.168.1.15:8000).

This URL is embedded into the printable desk QR poster below. When customers scan it on mobile, their phone browser opens this link.
